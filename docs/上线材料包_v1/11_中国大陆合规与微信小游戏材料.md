# 中国大陆合规与微信小游戏材料

版本：v1　日期：2026-11-09  
性质：产品经理的合规梳理，**不是法律意见**。正式上线前必须请熟悉网信和宗教事务法规的律师确认。

---

## 1. 结论：最大的风险不是技术，是《互联网宗教信息服务管理办法》

《互联网宗教信息服务管理办法》（国家宗教事务局等五部门，2022 年 3 月 1 日施行）有三条和我们直接相关：

| 条款 | 内容（摘要） | 对启扉的影响 |
| :--- | :--- | :--- |
| 第六条 | 通过网站、应用程序、公众账号等向公众提供宗教教义、宗教知识、宗教活动等信息，需要取得《互联网宗教信息服务许可证》 | 启扉的“来源”页、经文、节日说明可能被认定为宗教信息 |
| 第十五条 | 只有取得许可证的宗教团体、宗教院校和寺观教堂，才能在自建平台上由教职人员讲经讲道 | 个人或普通公司基本拿不到这张许可证 |
| 第十七条 | 除上述情形外，任何组织或个人不得在网上传教、组织宗教活动，**不得以文字、图片、音视频等方式直播或者录播拜佛、烧香、受戒、诵经、礼拜**等宗教仪式 | **诵经录音、礼佛三拜、上香直接撞上这一条** |

来源：[中国网信网转载全文](https://www.cac.gov.cn/2021-12/20/c_1641594960049078.htm)、[澎湃新闻转载](https://www.thepaper.cn/newsDetail_forward_15924965)、[英文译本](https://www.chinalawtranslate.com/internet-religious-information/)

**判断**【推断，待律师确认】：
- 启扉的定位是“文化体验”，不是传教，但审核员和监管不一定这样理解。
- **风险最高的是“自有诵经录音”**：真人诵经录音放进面向公众的产品，很接近第十七条说的“录播诵经”。
- 其次是“礼佛”“上香”“诵读”这些仪式玩法。
- 风险较低的是：建筑、四季、扫院子、照顾动物、节日知识、礼仪常识。

## 2. 推荐的分发策略

| 渠道 | 内容 | 理由 |
| :--- | :--- | :--- |
| **国际版**（现在的 GitHub Pages 网页、海外应用商店） | 完整内容：诵读、录音、仪式记录 | 不受上述办法约束；面向海外和华人社区 |
| **国内版**（微信小游戏、国内应用商店） | **世俗版**：扫院子、照顾和送养动物、建筑与四季、节日知识、礼仪常识；**不含**诵经音频、礼佛和上香操作、经文全文 | 避开第十七条；保留产品核心（照顾动物、安静的寺院生活） |

代码上这件事不难：平台已经有“版本”和“选项”的概念。国内版可以做成一个构建开关：
- 关掉 `options.voice` 和 `content`，诵读入口改为“经典简介”（只介绍，不呈现全文）；
- 礼佛、上香、布施按钮从操作改为“礼仪小知识”卡片；
- 资源循环保持不变（扫院子 → 存粮 → 照顾动物）。

**这件事要你拍板**：国内版做不做、做成什么样。建议先咨询律师，再决定。

## 3. 自有录音计划因此调整

- 05 号文件的 HAN-01《心经》录音**先只用于国际版**。
- 授权协议（06 号文件）第二条已写明平台范围，签约时把“微信小游戏”从授权范围里拿掉，或者注明“仅在法律允许的地区使用”。
