## 3. “启扉” 检索

- 网页检索“启扉 商标”没有找到任何注册或使用记录。
- 但公开网页**看不到**中国商标局数据库的全部内容。必须在 [国家知识产权局商标网上服务系统](https://sbj.cnipa.gov.cn) 用“启扉”“启 扉”“QIFEI”“啓扉”各查一次，看第 9、28、35、41、42 类有没有近似商标（例如“启飞”“启菲”“齐飞”在同类里也可能被判近似）。

## 4. 推荐的商标方案

**方案 1（推荐）：中文“启扉”+ 英文组合名**
- 中国：申请“启扉”文字商标，同时申请 Logo 图形商标（门 + 光，方向 A）。
- 英文：用 **“Qifei · Threshold”** 或 **“Threshold by Qifei”**。“Qifei” 是显著部分，Threshold 降为描述性副标题，不单独主张权利。
- 优点：中文名不变，现有设计不用改；英文可注册性大幅提高。

**方案 2：英文另起一个可注册的名字**
- 方向：自造词，比如 “Liminara”（liminal 门槛 + -ara）或 “Openway”。需要单独做一轮检索。
- 缺点：品牌板和所有英文文案都要改。

**方案 3：接受风险继续用 “Threshold”**
- 只作为网站名，不申请商标、不上应用商店。一旦上 App Store 或 Steam，被投诉下架的风险高。**不推荐。**

## 5. 建议申请的类别（中国，尼斯分类第 12 版）

| 类别 | 内容 | 优先级 |
| :--- | :--- | :--- |
| 第 9 类 | 可下载的游戏软件、手机应用程序 | 必须 |
| 第 41 类 | 在线游戏服务、文化活动、教育信息 | 必须 |
| 第 42 类 | 软件即服务、网站设计（平台属性） | 建议 |
| 第 35 类 | 广告、在线商店（将来如有周边或广告业务） | 可选 |
| 第 28 类 | 游戏器具、玩具（将来做实体周边） | 可选 |

费用参考：中国商标局官费每类 270 元（10 个商品以内，网上申请），代理费每类约 300–800 元。三类（9、41、42）合计约 1,700–3,200 元。审查周期约 6–9 个月。以上为截至本文日期的常见价格，以官方和代理报价为准。

## 6. 下一步

1. 你决定采用哪个方案（推荐方案 1）。
2. 委托商标代理人在中国商标局数据库正式检索“启扉”及近似字（1–3 个工作日）。
3. 无冲突则立即提交第 9、41、42 类申请。
4. 如果要进海外应用商店，再查美国（USPTO）和欧盟（EUIPO）的“Qifei”。
