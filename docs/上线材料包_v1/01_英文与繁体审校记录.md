## 2. 本轮改动

### 2.1 English

| key | 原文 | 改为 | 原因 |
| :--- | :--- | :--- | :--- |
| `status.next` | In production next | Coming next | 原句不自然；状态标签要短 |
| `version.sikhism.gurdwara.place` | None yet | Not yet | 和其他未开放版本统一 |
| `notice.th.alms` | …stay quiet and do not ask for a blessing. | …stay quiet and do not touch the monk. If the monks chant a blessing, listen with palms joined. | **事实修正**：泰国托钵后僧人常诵祝福偈（ยถา สัพพี），“不要求祝福”会让人以为没有祝福这一环 |
| `cal.note.th` | …estimated from the moon… | 2026 年按泰国通行年历，2027 起估算 | 佛日改用真实年历（见 03 号文件第 5 节） |
| 菩提静院 `krap.body` | forehead, palms and elbows touch the floor | five points: forehead, both palms and both knees, with the elbows close to the knees | **事实错误**：五体投地是额头、两掌、两膝着地，不是两肘 |
| 菩提静院 `alms.body`、`alms.pourBody` | 同上两处 | 补“合掌听祝福”；回向对象写明“已故的亲人和一切众生” | 与泰国习俗一致 |
| 菩提静院 `hint.wanPhra` | probably an observance day | an observance day | 2026 年起有确切日期 |

### 2.2 繁體中文

| 位置 | OpenCC 结果 | 改为 | 原因 |
| :--- | :--- | :--- | :--- |
| 平台 3 处 | 佈施 | 布施 | 佛教術語在台灣寫「布施」；「佈施」是誤用 |
| 平台 `type.nianfo` | 持名唸佛 | 持名念佛 | 台灣佛教界通用「念佛」 |
| 山寺小院 | 唸經、唸到 | 念經、念到 | 同上 |
| 山寺小院經題 | 唸佛 | 念佛 | 同上 |
| 平台 `privacy.body` | 賬號 | 帳號 | 台灣慣用「帳號」 |

这些修正已经写进 `tools/gen-zh-tw.py` 的 `FIX` 表，重新运行脚本也会保留。

### 2.3 逐条看过、决定不改的

- 「介面」「資訊」「程式」「螢幕」「儲存」「支援」：这些是台湾用语，保留。香港用户如果需要，另做 `zh-HK`（「界面」「資訊」「程式」「熒幕」）。
- 「迴響」：台湾两种写法都通行，保留。
- 「平臺」「這臺」：s2twp 的标准结果。教育部字典以「台」为通行写法，「臺」为正体，两者都对。建议母语审校者定一种；目前保留「臺」。

审校者逐条看完后，在下表签字。签完后把姓名和日期发给开发，由开发改 `registry.js` 里的语言状态（`draft` → `ok`）。

审校重点：
1. 宗教词有没有冒犯或不准确（例如把 “alms” 写成 “begging”）。
2. 按钮能不能一眼看懂、够不够短（手机宽度 375 px）。
3. 复数、标点、引号（English 用 ’ 和 “ ”，繁体用「」或“”，全文统一）。
4. 有没有中式英语、大陆用语混进繁体。
