# 山寺小院 v4

在 v3（`../temple-yard/`，保持不动）的基础上做的“最小可验证升级包”。美术、季节时辰、殿内外和动物系统都没有重写，只做增量修改。

## 改了什么

### 1. 存档更可靠
- 存档键名不变（`temple-yard-save-v1`），v3 的进度可以直接接着玩。
- 新增 `ver: 2`、`tut`（新手引导进度）、`ads`（当天随喜次数）、`playSec`（累计游玩秒数）。
- 读档先以默认存档为底合并，再做版本迁移：老玩家（看过开场或救助过动物）直接跳过新手引导。
- 每次写入前先把上一份完好的存档存到 `temple-yard-save-v1.bak`。主存档损坏时自动从备份恢复；备份也坏了就新建，并提示玩家。
- 写入失败只提醒一次，建议导出存档码。
- 第一次救助成功后，向浏览器申请持久存储，减少 iOS 长时间不访问被清存档的风险。
- **存档码**：在“送养册”底部导出或导入。格式 `SYXY2:内容:校验码`，导入前会校验并显示摘要，确认后才覆盖；导入时把“上次在线时间”设为现在，防止刷离线收益。

### 2. 广告改为“随喜”
- 删除“看广告治好”和“看广告领粮食包”。动物的伤病、饥饿相关界面里不再出现任何广告入口，治疗只能靠药和时间。
- 商店新增“随喜”分区：自愿观看一段广告，奖励给玩家自己的功德（30 + 10 × 木鱼等级），每天 3 次。
- 新存档前 3 分钟不显示随喜入口。
- 分区里固定写着“当前为模拟广告，不产生真实收入”。界面上没有任何“支持公益”的说法。

### 3. 第一分钟
- 第一只橘猫不再固定 6 秒出现：进院后敲满 5 下木鱼，或 20 秒后出现。
- 橘猫身上有呼吸光圈和爪印气泡，直到玩家点开它；开启“减少动态效果”时光圈不动。
- 玩家在殿里时，左上角出现“山门外有动静 →”，点它回到院子。
- 第一碗粥免费：“喂一碗粥（小院存粮）”不扣功德也不扣存粮，喂完提示“以后的饭食，靠你积的功德”。
- **目标行**：场景和底部面板之间常驻一行目标，按优先级显示：新手步骤 → 给受伤动物上药或换药（还差多少功德）→ 给饿的动物添饭 → 再积多少功德升级木鱼。数字都来自现有价格。
- **消息队列**：故事类消息（动物到来、痊愈、送养）至少显示 3.5 秒，不会被操作提示顶掉；同类消息去重，队列最多 4 条。离线回来只发一条汇总。
- **木鱼浮字**：0.4 秒内的连敲合并成一条“功德 +累计”，只在面板里上浮，不压到目标行。功德每敲一下都立即入账。

### 4. 诵经：一敲一字
- 文案统一为“敲木鱼诵经 · 一敲一字”。
- 进度显示“第 n/M 句 · 百分比”。
- 每诵完一句：一声轻磬，加一点功德。整句奖励合计是整部奖励的三成，平均分到每一句。
- 存档里的诵经进度仍是字的位置，不需要迁移。

### 5. 读屏和键盘
- 画布有 `role="img"` 和说明文字；页面有一个隐藏的 `aria-live` 播报层，重要消息和目标变化会同步播报，同一句 2 秒内不重复。
- 新增 H 键查看快捷键。
- 焦点在输入框里时，空格、M、H 等快捷键都不会触发。

## 和审查规格不一样的地方

| 规格 | 实际做法 | 原因 |
| :--- | :--- | :--- |
| 浮字生成在目标行之上 | 目标行放在场景底边，木鱼浮字只在面板内上浮 | 木鱼在面板里，浮字往上飘一定会穿过分界线；放在面板内最不挡东西 |
| 诵经时也显示目标行 | 诵经时隐藏目标行 | 经文卡片已经显示“第 n/M 句”，再加一行会压住卡片底部 |
| 每诵完一句发一条 toast | 句级反馈显示在经文卡片里 | 自动诵经时每几秒一句，toast 会刷屏 |
| 每句至少 1 功德 | 整部奖励三成平均分配 | 心经有 52 句，每句至少 1 会让句级奖励超过上限 |
| 动物可以走到画面最前方 | 动物活动范围往后收了一点 | 避免被目标行挡住 |

## 验收

用 Node 跑了 18 项自动检查，覆盖审查里的存档样本 F1–F6：

- 新存档：敲 5 下 1 秒内出现橘猫；不敲 20 秒后出现；到来提示连敲 30 下仍显示 3.5 秒以上。
- 殿内提示可见且能回院子；第一碗粥不扣功德和存粮。
- 连敲 10 下功德准确；浮字合并；三种屏幕尺寸下浮字不进目标行。
- 受伤动物不看广告也能治好；目标行缺口和价格一致。
- 随喜前 3 分钟隐藏、每天 3 次、第 4 次被拦、奖励给功德。
- 老存档（看过开场 / 救助过 2 只 / 诵经停在第 137 字）都跳过引导，不额外生成动物，诵经停在原位。
- 存档损坏新建、从备份恢复、读不到存储都不崩溃；写入失败只提醒一次。
- 存档码导出再导入一致，改动会被校验拦下，导入后上次在线时间是现在。
- 离线 2 小时回来只有一条汇总。
- 四季、时辰、雨雪、殿内外、所有弹窗都能正常绘制。

还没做的：真实读屏软件（VoiceOver、NVDA）实测、真机实测。

## 运行

双击 `山寺小院v4.html`（单文件）即可。开发时用 `index.html`。
