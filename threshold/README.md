# 启扉 / Threshold：平台第一阶段

多信仰文化体验平台的底座。原版《山寺小院》（`../temple-yard/`）一行没改；平台进入的是重写后的汉传佛教包。

## 能做什么

- **选传统和版本**：8 个传统，佛教下 5 个版本。只有“汉传佛教 · 山寺小院”能进入；其余进入筹备页，列出上线前缺的五项。
- **语言与声音分开选**：界面语言、原文、对照译文、诵读声音四项独立。不可选的项灰掉并写明原因；声音分“机器朗读 / 参考录音 / 自有录音”三类标注。
- **内容来源页**：6 部经、咒、偈的类型、版本、出处、许可、审核状态；每段声音的权利链和还缺的材料。
- **平台语言**：简体中文（基准）、English（AI 起草，待母语审校）、两种伪语言（加长 40%、从右往左）用来测排版。
- **存档**：新键 `threshold-save-v1`，带备份和存档码。第一次打开时读取旧的 `temple-yard-save-v1`（v1/v2/v3 都支持），旧键只读不写。
- **深链接**：`#v=buddhism.han&ui=en&src=lzh&tr=none&voice=sys.hall` 直接打开某个版本的设置；指向未开放版本时落到筹备页。
- **开发页**：`#view=brand` 品牌板（三个 Logo 方向），`#view=scripts` 文字压力测试（汉字、拉丁、泰文、天城文、阿拉伯文、希伯来文）。

## 第二阶段：汉传佛教包（已完成）

`traditions/buddhism.han/game/` 是从 `../temple-yard/`（Codex 分支最新版）复制出来再改的，原版一行没动。

- **平台选择带进游戏**：在平台选的诵读声音（清朗 / 庄重 / 寺院回响）进入游戏后生效；选“参考录音”时，打开《心经》直接播放 CC0 真人录音并标明“非本产品录制”。地址栏里的选择优先于存档。
- **资源循环改造**：
  - 敲木鱼、诵经、礼佛、上香、撞钟、供奉、祈福、敲磬击鼓只记入修行簿，不再产出任何可花的东西，界面上也不再出现“功德 +N”。
  - 新资源“存粮”来自出坡：院子里会长出落叶堆（春天落花、夏天断枝杂草、冬天积雪），点一下扫一次，扫两次清掉一堆。底部新增“出坡”按钮，会标出可扫的地方。
  - 小沙弥改成帮忙扫地；送养时领养人留下一袋粮食作谢礼。
  - 商店用存粮；“换更好的木鱼”改成“添置扫帚和簸箕”。
  - 广告改名“支持我们：看一段广告”，只在商店，开局 3 分钟后出现，每天 3 次，奖励存粮，写明模拟广告不产生真实收入。
- **新存档**：`threshold-han-save-v1`。第一次打开时读取旧的 `temple-yard-save-v1`，功德 1:1 折成存粮、木鱼等级折成扫帚等级，修行记录保留；旧存档只读不写，原版游戏随时可以接着玩。
- **顶部“平台”按钮**回到平台首页。

## 第三阶段：英文版与声线同步（已完成）

- **游戏英文界面**：在平台把界面语言选成 English，进入游戏后全部界面、提示、动物卡、商店、祈福牌、经名和读屏播报都是英文。词表在 `traditions/buddhism.han/game/i18n-en.js`（整句对照 + 带数字和名字的句式模板），在文字绘制出口统一翻译，游戏逻辑没改。
  - 英文按词断行；按钮文字放不下时自动缩小；任何一行都不会画出屏幕。
  - 数字用 k / M；动物名字有对应的英文名；时辰显示为“Horse hour”这类说法。
  - 经文原文和竖排经题保持古典汉文，不翻译。
- **覆盖检查**：测试把游戏各个界面和提示都走一遍（7 种动物 × 受伤/饥饿、全部喂食与照顾、6 部经、殿内外、四季、商店、广告、离线），英文模式下漏翻为 0。
- **声线同步**：在游戏“声线”弹窗里改的声音会写回平台存档；平台存档不存在时不会新建。

## 需要人来完成的事

这些不是代码能替代的，完成前对应内容保持“草稿 / 筹备中”：

1. **母语审校**：English 文案（平台与游戏）由 AI 起草，需英语母语者审校；其他文字的样本都只是排版测试。
2. **传统顾问**：经文底本、断句、经名英译，以及汉传佛教包整体的礼仪表述，需要汉传佛教顾问审定。
3. **自有录音**：签约诵读者、校音人和完整授权（见 `docs/诵读声音与自有录音方案_v0.1.md`）。
4. **品牌**：“启扉 / Threshold”的商标检索。
5. **其他传统**：泰国上座部、印度教、基督宗教、伊斯兰、犹太教等版本都需要对应顾问和母语审校后才能制作；平台里如实显示“筹备中”，不会用换皮内容代替。
6. **真机测试**：iPhone 微信、安卓手机上的朗读与手感。
