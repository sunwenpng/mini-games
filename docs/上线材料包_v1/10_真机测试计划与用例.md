## 1. 已经做过的（模拟，不等于真机）

在 Mac 上的浏览器里，用 375×812 手机尺寸、安卓 Chrome 的 User-Agent 模拟：

| 检查 | 结果 |
| :--- | :--- |
| 平台设置页：隐私说明、隐私政策链接、繁体文案 | 通过；无横向溢出 |
| 隐私政策与用户协议页（深色模式） | 通过；无横向溢出 |
| 菩提静院 中文界面：礼佛说明（已改为“两膝”） | 通过 |
| 菩提静院 泰文界面：กราบเบญจางคประดิษฐ์ 说明 | 通过 |
| 菩提静院：今天是否佛日（泰国时间 2026-11-10，不是佛日） | 判断正确 |
| 面板打开时提示条挡住“拜下”按钮 | **发现问题，已修**：面板打开时提示条移到顶部 |
| 网络字体阻塞首屏（国内打不开 Google Fonts 会白屏） | **发现问题，已修**：字体改为不阻塞加载，打不开时用系统字体 |
| 这台 Mac 的朗读语音 | 泰语 1 个（Kanya，本地）；中文多个（婷婷等） |

**模拟测不出来的**：真实的触摸手感、微信内置浏览器的限制、iOS 的语音列表、真机性能和发热、“添加到主屏幕”、静音键。下面这些必须用真机测。

## 3. 测试用例

每条记录：通过 / 不通过 / 截图。不通过的写清楚设备、系统版本、操作步骤。

### A. 打开与网络

| 编号 | 步骤 | 预期 |
| :--- | :--- | :--- |
| A1 | 在微信里打开分享链接 | 3 秒内看到首页（不等字体）；没有白屏 |
| A2 | 关闭 Wi-Fi、只用 4G 打开 | 同上 |
| A3 | Safari 打开后“添加到主屏幕”，从主屏幕图标进入 | 图标是“门 + 光”，全屏打开，名称“启扉” |
| A4 | 打开过一次后开飞行模式，再打开 | 平台和两个游戏都能打开（离线缓存） |

### B. 平台

| 编号 | 步骤 | 预期 |
| :--- | :--- | :--- |
| B1 | 设置里切换 简 / 繁 / English | 全部文字切换，无缺字、无英文 key 漏出 |
| B2 | 文字大小选“特大” | 无文字被裁切、无横向滚动 |
| B3 | 佛教 → 泰国上座部：不勾确认直接点进入 | 提示“请先勾选上面的确认” |
| B4 | 生成存档码 → 复制 → 清除浏览器数据 → 粘贴存档码 | 平台选择和两个游戏的进度都恢复 |
| B5 | 点“隐私政策与用户协议” | 打开页面，能返回 |

### C. 山寺小院

| 编号 | 步骤 | 预期 |
| :--- | :--- | :--- |
| C1 | 打开《心经》，选“清朗”声线 | 有人声朗读（系统语音）；没有中文语音的设备改用吟唱声并提示 |
| C2 | 选“参考录音” | 播放 CC0 真人录音，界面写明“非本产品录制” |
| C3 | 按手机静音键 / 调到最小音量 | iOS 静音键下网页声音的表现记录下来（iOS 网页音频不受静音键控制的情况很常见） |
| C4 | 扫地 10 分钟 | 存粮增加，不卡顿，手机不明显发热 |
| C5 | 繁体界面打开经文 | 经题、经文都是繁体，无简体字残留 |

### D. 菩提静院

| 编号 | 步骤 | 预期 |
| :--- | :--- | :--- |
| D1 | 泰文界面打开 | 泰文字形正确（上下元音、声调符号不重叠、不被裁切） |
| D2 | 诵读 → 礼敬文 → 自动 | 有泰语语音朗读；没有泰语语音的设备提示“只显示文字” |
| D3 | 早上 6–8 点外打开布施 | 提示时段，只能看演示，演示不扣米 |
| D4 | 早上 6–8 点（可改手机时间）布施 | 能放饭，一天只记一次 |
| D5 | 打开任意面板时触发提示 | 提示条在顶部，不挡按钮 |
| D6 | 照护 → 上药、起名、送养 | 流程完整 |
| D7 | 日历 | 今天如果是佛日，写“佛日”且**不带**“估算”（2026 年内）；2027 年的佛日带“估算” |

### E. 无障碍

| 编号 | 步骤 | 预期 |
| :--- | :--- | :--- |

| E2 | Android TalkBack：同上 | 同上 |
| E3 | 系统开启“减少动态效果” | 场景动画减少 |

## 5. 通过标准

- P0 设备上 A、B、C、D 组全部通过；
- 不通过项必须是“设备不支持”（例如没有泰语语音），并且产品给出了清楚的提示；
- E 组至少 VoiceOver 走通一遍。

预计用时：两人各一部手机，半天。
