# 云霄突围

竖屏 3D 飞机射击小游戏。自动开火，拖动躲弹幕，一路升级变强。

## 玩法

- 手机拖动屏幕，电脑移动鼠标或按方向键。
- 击毁敌机掉绿色经验，升级时三选一。
- 每隔一段时间出现敌方旗舰，击毁后获得高分和护盾。
- 飞机中心的红点才是受击判定。
- 结算获得金币，在机库做永久升级。

## 运行

用浏览器打开 `index.html` 即可，不需要安装任何东西。按 `M` 可以静音。

## 广告

广告由 `ad-kit.js` 管理，目前显示的是模拟广告。

| 位置 | 类型 |
| :--- | :--- |
| 死亡后复活（每局一次） | 激励广告 |
| 结算金币翻倍 | 激励广告 |
| 升级时全部拿走三个选项 | 激励广告 |
| 几局之后点“再来一局” | 插屏广告 |
| 菜单页底部 | 横幅广告 |

申请到微信广告位后，把 ID 填到 `game.js` 里的 `AD_UNITS`。

## 移植到微信小游戏

界面和 3D 模型全部画在 2D canvas 上（见 `render3d.js`），没有 HTML 按钮，也不依赖外部引擎。移植时主要替换入口、画布获取和触摸事件，这部分还没做。
