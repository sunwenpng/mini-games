## 2. HAN-01 诵读稿（玄奘译本，与游戏文字逐字一致）

标记：`/` 短停（半拍），`//` 换气，`///` 段落停顿（约 2 秒）。拼音只标易读错和有特殊读法的字。

> 观自在菩萨（pú sà），/ 行（xíng）深般若（bō rě）波罗（bō luó）蜜多时，// 照见五蕴（yùn）皆空，/ 度一切苦厄（è）。///
>
> 舍（shè）利子，/ 色不异空，/ 空不异色，// 色即是空，/ 空即是色，// 受想行（xíng）识，/ 亦复如是。///
>
> 舍利子，/ 是诸法空相，// 不生不灭，/ 不垢（gòu）不净，/ 不增不减。///
>
> 是故空中无色，/ 无受想行识，// 无眼耳鼻舌身意，/ 无色声香味触法，// 无眼界，/ 乃至无意识界，// 无无明，/ 亦无无明尽，// 乃至无老死，/ 亦无老死尽。// 无苦集灭道，/ 无智亦无得。///
>
> 以无所得故，/ 菩提萨埵（pú tí sà duǒ），/ 依般若波罗蜜多故，// 心无挂碍（guà ài）。/ 无挂碍故，/ 无有恐怖，// 远离颠倒梦想，/ 究竟涅槃（niè pán）。///
>
> 三世诸佛，/ 依般若波罗蜜多故，// 得阿耨（nòu）多罗三藐（miǎo）三菩提。///
>
> 故知般若波罗蜜多，/ 是大神咒，/ 是大明咒，// 是无上咒，/ 是无等等咒，// 能除一切苦，/ 真实不虚。///
>
> 故说般若波罗蜜多咒，/ 即说咒曰：//
> 揭谛（jiē dì）揭谛，/ 波罗揭谛，/ 波罗僧揭谛，/ 菩提萨婆诃（sà pó hē）。///

**读法说明**（以校音顾问意见为准）：
- “般若”读 bō rě，“波罗”读 bō luó，“菩提”读 pú tí，是汉传寺院的通行读法。
- “行深”“受想行识”的“行”读 xíng。
- 节奏：清朗随诵每分钟约 110–130 字；一字一拍，不拖腔，不加流行唱法的颤音。
- 不加背景音乐。法器只在 HAN-02 用。

## 3. TH-01 诵读稿（泰式巴利诵法）

请诵读者按自己寺院的习惯诵读，**不要模仿任何知名法师**。下面是游戏里显示的文字，录音必须和它逐字一致；如果诵读者的习惯不同，请先告诉校音人，再一起改文字。

```
นะโม ตัสสะ ภะคะวะโต อะระหะโต สัมมาสัมพุทธัสสะ   （三遍）

พุทธัง สะระณัง คัจฉามิ
ธัมมัง สะระณัง คัจฉามิ
สังฆัง สะระณัง คัจฉามิ
ทุติยัมปิ พุทธัง สะระณัง คัจฉามิ
ทุติยัมปิ ธัมมัง สะระณัง คัจฉามิ
ทุติยัมปิ สังฆัง สะระณัง คัจฉามิ
ตะติยัมปิ พุทธัง สะระณัง คัจฉามิ
ตะติยัมปิ ธัมมัง สะระณัง คัจฉามิ
ตะติยัมปิ สังฆัง สะระณัง คัจฉามิ

ปาณาติปาตา เวระมะณี สิกขาปะทัง สะมาทิยามิ
อะทินนาทานา เวระมะณี สิกขาปะทัง สะมาทิยามิ
กาเมสุมิจฉาจารา เวระมะณี สิกขาปะทัง สะมาทิยามิ
มุสาวาทา เวระมะณี สิกขาปะทัง สะมาทิยามิ
สุราเมระยะมัชชะปะมาทัฏฐานา เวระมะณี สิกขาปะทัง สะมาทิยามิ
```

- 用泰国寺院常见的“สังโยค”（音节连诵）节奏，每行之间换气。
- 五戒在真实场合是僧人领诵、在家人跟诵。这里录的是**单人完整诵读**，界面会写“练习跟诵”。
- 如果是僧人录音：录音过程不能有女性单独与僧人同处一室；请寺院安排在家众陪同。

## 4. 技术规格

| 项 | 要求 |
| :--- | :--- |
| 格式 | 48 kHz / 24-bit WAV，单声道干声 + 立体声空间声（如有） |
| 话筒 | 大振膜电容话筒，离嘴 20–30 cm，加防喷罩 |
| 环境 | 安静房间或寺院小殿；底噪低于 -60 dBFS；不开空调、风扇 |
| 电平 | 峰值 -6 到 -3 dBFS，不削波 |
| 遍数 | 每条完整录 3 遍，另外补录易错句 |
| 后期 | 只降噪、剪辑、轻压缩；**不修音高、不变速、不加合唱** |
| 母带 | 响度 -18 LUFS（± 1），真峰值 ≤ -1 dBTP；同时交 OGG（游戏用）和 WAV（存档） |
| 时间轴 | 每句起止时间（毫秒），JSON 或 CSV，用来在游戏里逐句高亮 |
| 命名 | `HAN-01_xinjing_v1_take2_master.wav`，版本号只增不改 |
| 哈希 | 交付时计算 SHA-256，写进 `pack.js` 的 `VOICES` |
