# 启扉 / Threshold：多信仰文化体验平台

多信仰文化体验平台的底座。原版《山寺小院》（`../temple-yard/`）一行没改；平台进入的是重写后的汉传佛教包。

线上：<https://sunwenpng.github.io/mini-games/threshold/>（汉传佛教加 `#ui=zh-TW` 或 `#ui=en` 切换繁体、英文；其余版本进入前需勾选“知道是未经审核的预览”）

## 能做什么

- **选传统和版本**：8 个传统家族、14 个版本，**全部可以进入**。“汉传佛教 · 山寺小院”是正式版；其余 13 个是要先确认的内测预览（见下面第五阶段）。
- **语言与声音分开选**：界面语言、原文、对照译文、诵读声音四项独立。不可选的项灰掉并写明原因；声音分“机器朗读 / 参考录音 / 自有录音”三类标注。
- **内容来源页**：6 部经、咒、偈的类型、版本、出处、许可、审核状态；每段声音的权利链和还缺的材料。
- **平台语言**：简体中文（基准）、繁體中文（OpenCC 转换，待审校）、English（AI 起草，待母语审校）、两种伪语言（加长 40%、从右往左）用来测排版。
- **存档**：新键 `threshold-save-v1`，带备份和存档码。第一次打开时读取旧的 `temple-yard-save-v1`（v1/v2/v3 都支持），旧键只读不写。
- **深链接**：`#v=buddhism.han&ui=en&src=lzh&tr=none&voice=sys.hall` 直接打开某个版本的设置；指向未开放版本时落到筹备页。
- **开发页**：`#view=brand` 品牌板（三个 Logo 方向），`#view=scripts` 文字压力测试（汉字、拉丁、泰文、天城文、阿拉伯文、希伯来文）。

## 第二阶段：汉传佛教包（已完成）

`traditions/buddhism.han/game/` 是从 `../temple-yard/`（Codex 分支最新版）复制出来再改的，原版一行没动。

- **平台选择带进游戏**：在平台选的诵读声音（清朗 / 庄重 / 寺院回响）进入游戏后生效；选“参考录音”时，打开《心经》直接播放 CC0 真人录音并标明“非本产品录制”。地址栏里的选择优先于存档。
- **资源循环改造**：
  - 敲木鱼、诵经、礼佛、上香、撞钟、供奉、祈福、敲磬击鼓只记入修行簿，不再产出任何可花的东西，界面上也不再出现“功德 +N”。
  - 新资源“存粮”来自出坡：院子里会长出落叶堆（春天落花、夏天断枝杂草、冬天积雪），点一下扫一次，扫两次清掉一堆。底部新增“出坡”按钮，会标出可扫的地方。
  - 小沙弥改成帮忙扫地；送养时领养人留下一袋粮食作谢礼。
  - 商店用存粮；“换更好的木鱼”改成“添置扫帚和簸箕”。
  - 广告改名“支持我们：看一段广告”，只在商店，开局 3 分钟后出现，每天 3 次，奖励存粮，写明模拟广告不产生真实收入。
- **新存档**：`threshold-han-save-v1`。第一次打开时读取旧的 `temple-yard-save-v1`，功德 1:1 折成存粮、木鱼等级折成扫帚等级，修行记录保留；旧存档只读不写，原版游戏随时可以接着玩。
- **顶部“平台”按钮**回到平台首页。

## 第三阶段：英文版与声线同步（已完成）

- **游戏英文界面**：在平台把界面语言选成 English，进入游戏后全部界面、提示、动物卡、商店、祈福牌、经名和读屏播报都是英文。词表在 `traditions/buddhism.han/game/i18n-en.js`（整句对照 + 带数字和名字的句式模板），在文字绘制出口统一翻译，游戏逻辑没改。
  - 英文按词断行；按钮文字放不下时自动缩小；任何一行都不会画出屏幕。
  - 数字用 k / M；动物名字有对应的英文名；时辰显示为“Horse hour”这类说法。
  - 经文原文和竖排经题保持古典汉文，不翻译。
- **覆盖检查**：测试把游戏各个界面和提示都走一遍（7 种动物 × 受伤/饥饿、全部喂食与照顾、6 部经、殿内外、四季、商店、广告、离线），英文模式下漏翻为 0。
- **声线同步**：在游戏“声线”弹窗里改的声音会写回平台存档；平台存档不存在时不会新建。

## 第四阶段：繁体中文、泰国上座部预览、节历与上线准备（已完成）

- **繁體中文**：平台界面（`locales/zh-TW.js`）和山寺小院（`game/i18n-zh-TW.js`）都能选繁体。用 OpenCC（台湾用语）生成，经文改用传统字形且逐字对应，转换可重复执行不会再改字。状态是“待母语审校”。
- **泰国上座部佛教 · 菩提静院**（`traditions/buddhism.theravada.th/`）：第二个可进入的版本，状态是“内测预览”，进入前必须勾选“知道这是未经审核的预览”。
  - 界面：泰语、English、简体中文；巴利文用泰文字母、拉丁转写或两者并列，对照译文可选泰语、English、中文。
  - 五段在家众常诵：礼敬文（三遍）、三皈依、五戒、三宝功德、慈心文。原文公有领域，译文是 AI 草稿，全部标 draft。
  - 玩法和汉传刻意不同：清晨 6–8 点才能托钵布施（一天记一次，可看演示）；三拜（五体投地）；供花、烛、香；扫菩提叶得米，照顾寺里的狗和猫；热季、雨季、凉季；雨安居；按月相画月亮；檐角风铃。不做放生，全包没有广告。
  - 界面用网页 DOM（泰文断行交给浏览器），场景用 Canvas，验证了第一批方案里“网页界面 + Canvas 场景”的路线。
- **节历**（`core/calendar.js`）：汉传按农历推算佛诞、观音、盂兰盆、地藏、腊八和初一、十五；泰国用政府公布的四大节日日期，佛日按月相估算并标“估算”。平台版本页和两个游戏里都会显示。
- **锡克教纸面推演**（`traditions/sikhism.gurdwara/pack.js` + `docs/Claude_非寺院型传统纸面推演_锡克教_v1.md`）：证明现有接口能描述一个以服务（Seva、Langar）为中心的传统，不开放入口。
- **设置**：文字大小（标准 / 大 / 特大）、动效（跟随系统 / 减少 / 保留）、隐私说明。存档码现在同时包含平台选择和各传统里的游戏进度，只接受已知的存档键。
- **品牌与安装**：iOS、安卓圆形与方圆裁切、单色、黑白打印的图标板；`manifest.webmanifest` 和 PNG 图标，可以“添加到主屏幕”；`sw.js` 网络优先的离线缓存（在线时永远拿最新版）。
- **上线检查**：`node tools/release-check.mjs` 列出每个包离正式发布还差什么（目前 94 项，全部是顾问、母语审校和自有录音）。
