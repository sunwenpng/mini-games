# 启扉 隐私政策

> 本政策按项目当前的真实技术实现写成：没有账号、没有服务器端数据库、没有统计和广告 SDK。以后如果加入任何收集数据的功能，必须先改本政策，再上线功能。

## 一、一句话

**我们不收集你的个人信息。** 你在启扉里的选择和游戏进度只存在你自己设备的浏览器里，我们看不到。

## 二、保存在你设备上的内容

| 内容 | 存在哪里 | 用途 | 怎么删除 |
| :--- | :--- | :--- | :--- |
| 平台选择（界面语言、经文、译文、声音、显示设置、“开放时提醒我”） | 浏览器本地存储 `threshold-save-v1` | 下次打开时记住你的选择 | 清除本站的浏览器数据 |
| 山寺小院、菩提静院的游戏进度 | 浏览器本地存储 `threshold-han-save-v1`、`threshold-th-save-v1` 等 | 继续游戏 | 同上 |
| 离线缓存（网页文件） | 浏览器的 Service Worker 缓存 | 断网时也能打开 | 同上 |
| 存档码 | 只在你点击“生成存档码”时显示在屏幕上 | 换设备时自己复制、粘贴 | 我们不保存 |

这些数据不会自动上传。存档码由你自己复制和保管，我们不会收到。

## 三、第三方服务

启扉没有接入任何统计、广告、登录或支付服务。但下面三项属于网页正常运行所需，第三方可能会看到你的网络地址（IP）等技术信息：

| 第三方 | 用途 | 可能看到的信息 | 对方的隐私政策 |
| :--- | :--- | :--- | :--- |
| GitHub Pages（GitHub, Inc.） | 网页托管 | IP、浏览器类型、访问时间（服务器日志） | https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement |
| Google Fonts（Google LLC） | 显示字体 | IP、浏览器类型 | https://policies.google.com/privacy |
| 浏览器自带的朗读语音 | 机器朗读经文 | 部分浏览器（例如 Chrome 的在线语音）会把要朗读的文字发到浏览器厂商的服务器合成；设备本地语音不联网 | 以浏览器厂商的说明为准 |

游戏里的“广告”是模拟的占位，不联网、不追踪。

## 四、未成年人

启扉不需要注册，也不收集任何人的个人信息，包括未成年人。建议未成年人在监护人陪同下了解宗教文化内容。

## 五、你的权利

因为我们不持有你的个人信息，所以无从查阅、更正或删除。你可以随时在浏览器设置里清除本站数据，删除全部存档。

## 六、将来的变化

如果将来上线微信小游戏或应用商店版本，平台本身可能会收集账号标识（例如微信 OpenID）。届时我们会：
1. 先更新本政策并在产品里显著提示；
2. 按《个人信息保护法》和平台规则，单独征得你的同意；
3. 只收集运行功能所必需的最少信息。

## 七、联系我们

对本政策有任何疑问，请写信到 [联系邮箱]。我们会在 15 个工作日内回复。

# Threshold Privacy Policy (English)

Effective: [launch date]. Version 1 (drafted 2026-11-09). Operator: [entity]. Contact: [email].

**In short: we collect no personal data.** Your choices and game progress stay in your own browser on your own device; we cannot see them.

**Stored on your device:** platform choices (`threshold-save-v1`), game progress (`threshold-han-save-v1`, `threshold-th-save-v1`), an offline cache of the site files, and nothing else. A save code is shown on screen only when you ask for one; we never receive it. Clear this site's browser data to delete everything.

**Third parties needed to run a web page:** GitHub Pages hosts the site and Google Fonts serves the fonts; both may see your IP address and browser type, as with any website. Some browsers' online text-to-speech voices send the text being read to the browser maker's servers; on-device voices do not. There is no analytics, advertising, login or payment SDK. The in-game "ads" are simulated and make no network calls.

**Children:** no registration and no personal data from anyone, including children.

**Changes:** if a future WeChat or app-store version needs an account identifier, we will update this policy first and ask for your consent separately.
