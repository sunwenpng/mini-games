## 核对时发现并纠正的地方

- 原以为是“横三世佛”的善缘寺大殿，原图说明写的是**三身佛**（法身、报身、应身），已按三身佛介绍。
- 原以为是“罗陀与黑天”的温达文神像，原图说明写的是**罗摩与悉多**，已改。
- 原以为是天主教堂的彩色玻璃窗，实际在苏格兰教会（新教）的圣马太教堂，已移到新教版本。
- 藏传“释迦牟尼佛”像在比利时一座藏传佛教中心的花园里，不在西藏；“如意轮观音”在奈良东大寺（华严宗），不是禅寺。介绍里都写明了。
