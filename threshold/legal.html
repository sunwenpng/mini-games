隐私政策

我们不收集你的个人信息。启扉没有账号、没有服务器端数据库，也没有接入任何统计、广告、登录或支付服务。你的选择和游戏进度只存在你自己设备的浏览器里，我们看不到。

存在你设备上的内容用途
平台选择（语言、经文、译文、声音、显示设置、开放提醒）下次打开时记住
山寺小院、菩提静院的游戏进度继续游戏
网页文件的离线缓存断网也能打开

存档码只在你点击“生成存档码”时显示在屏幕上，由你自己复制保管，我们不会收到。清除本站的浏览器数据即可删除全部存档。

网页运行需要的第三方：网页托管在 GitHub Pages，字体来自 Google Fonts，这两家会像访问任何网站一样看到你的网络地址和浏览器类型。部分浏览器的在线朗读语音（例如 Chrome 的在线语音）会把要朗读的文字发到浏览器厂商的服务器合成；设备本地语音不联网。游戏里的“广告”是模拟的占位，不联网、不追踪。

未成年人：不需要注册，不收集任何人的个人信息。建议未成年人在监护人陪同下了解宗教文化内容。

将来的变化：如果将来上线微信小游戏或应用商店版本、需要账号标识，我们会先更新本政策，并单独征得你的同意。

你可以个人、非商业地使用启扉，分享链接和截图用于介绍、评论、教学。

请不要用启扉的内容嘲讽、贬低任何宗教或信众；把界面、图像、录音拿去做商业用途；冒充启扉或宗教机构；干扰网站运行。

Privacy policy and terms (English)

We collect no personal data. There is no account, no server-side database, and no analytics, advertising, login or payment SDK. Your choices and game progress stay in your own browser; a save code appears on screen only when you ask and we never receive it. Clear this site's browser data to delete everything.

The site is hosted on GitHub Pages and fonts come from Google Fonts; like any website, they see your IP address and browser type. Some browsers' online text-to-speech voices send the text being read to the browser maker's servers. The in-game "ads" are simulated and make no network calls.

Threshold is a cultural experience. It does not represent any religious body, gives no religious guidance and promises no spiritual result. Preview and unreviewed versions may contain errors. Use it personally and non-commercially; do not use it to mock any religion or believers. Source scriptures are public domain; the Mandarin Heart Sutra reference recording is CC0 from Wikimedia Commons. Saves are your responsibility. Report errors via GitHub Issues.
