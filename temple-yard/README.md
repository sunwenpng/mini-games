# 山寺小院

深山小寺里的治愈小游戏：在院子里敲木鱼、上香、撞钟，进大雄宝殿礼佛、供奉、祈福、诵经，同时收留山门外的流浪猫狗和受伤的小鸟。

## 玩法

**院子里**
- **敲木鱼**：点木鱼（或按空格）得功德。
- **上香**：三炷香燃 4 分钟，期间所有功德翻倍。院子和殿里的香炉同步燃着。
- **撞钟**：梵钟余音十几秒。早上 5–9 点、傍晚 5–9 点各有一次晨钟、暮钟加持。
- **救助小动物**：点小动物可以喂食、摸摸、上药、起名、送养。喂错食物会提示真实的养护知识，比如大多数成年猫乳糖不耐受。
- **商店**：用功德买粮食和药，升级木鱼、请小沙弥自动敲木鱼、扩建猫窝。

**大雄宝殿里**（点院子里的殿门或“进殿”）
- **礼佛**：第一人称三拜，每拜一声磬。
- **供奉**：供花、供果、供水、供灯，摆在供桌上十分钟。
- **祈福**：平安、健康、学业、事业、姻缘、家人，得到一块祈福牌。
- **敲磬、击鼓**：点左下角的磬、右下角的鼓。
- 亲近够了、起过名字的猫，会跑进殿里睡在蒲团上。

**诵经**（院子和殿里都能诵）
- 六部可选：心经、大悲咒、往生咒、金刚经偈、六字真言、念佛。
- 竖排经文，敲一下木鱼诵一句；“自动诵经”会一句一句念出来。
- 念经用设备自带的中文语音；没有中文语音的设备会用合成的吟唱声代替。
- 木鱼伴奏可以关掉，只听念经。

**天时**
- 天色、季节跟着真实时间走：春天嫩绿、夏天浓绿有萤火虫、秋天银杏金黄落叶、冬天枯枝积雪。
- 日出日落有霞光、光芒和暖色；会随机下雨（冬天下雪），雨后地面有水洼。
- 右上角“天时”可以切换时辰、季节和天气，方便看不同的样子。

## 运行

双击 `山寺小院.html` 即可，所有代码都在这一个文件里。开发时用 `index.html`，它会加载 `ad-kit.js` 和 `game.js`。

## 广告

`ad-kit.js` 管理广告，目前是模拟广告：

| 位置 | 类型 |
| :--- | :--- |
| 商店里“看广告领粮食包” | 激励广告，每天 8 次 |
| 受伤小动物“看广告治好” | 激励广告，每天 20 次 |

## 技术

- 全部画在一块 canvas 上，没有图片素材，没有外部依赖。
- 声音全部用 WebAudio 合成，带一层模拟大殿的混响。
- 经文文本取自通行版本，上线前建议再对照校对一遍。
