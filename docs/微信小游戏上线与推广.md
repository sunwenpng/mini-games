# 微信小游戏上线与推广方案

> 平台规则经常变。下面标“需核实”的地方，上线前请以微信公众平台当时的官方文档为准。

## 1. 先上哪一款

| 游戏 | 适合程度 | 原因 |
| :--- | :--- | :--- |
| 云霄突围 | 适合先上 | 射击类，没有敏感内容，激励广告位天然 |
| 山寺小院（完整版） | 不建议直接上 | 国内对线上宗教活动和游戏里的宗教内容管得严 |
| 山寺小院（国内版） | 可以改后上 | 去掉佛像、礼佛、上香、诵经、祈福，保留小动物救助和敲木鱼解压 |

山寺小院相关的规定：2022 年 3 月起施行的《互联网宗教信息服务管理办法》，要求非宗教团体不得在网上组织宗教活动，也不得以图文、音视频等方式展示拜佛、烧香、诵经等宗教仪式。游戏审核同样会卡宗教内容。所以建议：

- **国内微信版**：做成“小院收养猫狗”，木鱼作为解压玩具保留。木鱼能否过审需要实际提交验证。
- **完整版**：放在网页（GitHub Pages）和海外平台（itch.io、CrazyGames、Google Play）。

## 2. 资质和流程

1. **注册小游戏账号**：微信公众平台注册小程序，选择小游戏。个人主体也能注册，但企业主体在广告、支付、类目上限制更少（需核实）。
2. **备案**：2023 年 9 月起，新上架的小程序和小游戏需要先完成备案。
3. **软件著作权**：通常需要（需核实）。正常申请约 1–2 个月，可以加急。
4. **游戏自审自查报告**：按平台模板填写。
5. **版号**：要做内购、付费就必须有版号。只靠广告赚钱、完全免费的游戏，是否需要版号以当时规则为准（需核实）。
6. **提交审核 → 上线。**

建议第 1 周就开始申请软著和备案，同时做移植，两边并行。

## 3. 技术移植

两款游戏本来就只用一块 canvas，移植工作量小：

| 网页版 | 微信小游戏 |
| :--- | :--- |
| `document.getElementById('game')` | `wx.createCanvas()` |
| `pointerdown` 事件 | `wx.onTouchStart` |
| `localStorage` | `wx.setStorageSync`（`ad-kit` 已支持） |
| WebAudio | `wx.createWebAudioContext()` |
| 模拟广告 | `AdKit.wechatProvider(wx)`，填入广告位 ID 即可 |
| 系统朗读诵经 | 小游戏里没有，需要换成录好的音频（自己录或购买授权） |

- 也可以先用微信官方的适配层（weapp-adapter）补齐 `window`、`document`，改动更少。
- 字体：安卓手机没有宋体，标题会退回系统字体，可以考虑打包一个小字体子集。
- 包体：现在每款只有一两百 KB，远低于主包限制。

## 4. 赚钱：广告

- **流量主**：小游戏累计用户达到门槛（大约 1000 人，需核实）后开通。
- **激励视频**：收入主力。用户主动选择看，体验好、单价高。
  - 云霄突围：复活、金币翻倍、升级全部拿走。
  - 小院：粮食包、立刻治好。
- **插屏**：只在一局结束后放，并且隔几局一次，`ad-kit` 已经做了频控。
- **横幅**：只放菜单页，收益低，不影响游戏就行。

## 5. 推广

### 自然流量（先做，几乎不花钱）
- **名字和简介带搜索词**：比如“飞机大战”“救助小猫”“电子木鱼”，方便在微信“搜一搜”被找到。
- **好友分享**：分享卡片要有内容。比如分享自己的最高分、送养证书、刚救的小猫。
- **不能诱导分享**：微信明令禁止“分享才能领奖励”“分享到群才能复活”，会被处罚。分享只能是玩家自愿的。

### 内容平台（主力）
- **抖音、视频号、小红书**发短视频：
  - 小院：“功德 +1”、雨夜收留一只受伤小猫、送养时小猫回头看一眼。
  - 云霄突围：满屏弹幕极限躲避、打旗舰的高光片段。
- 视频里放小游戏的名字或链接，引导搜索进入。

### 付费买量（数据跑通后再做）
- 在腾讯广告投“小游戏推广”，先用 1000–3000 元小预算测试。
- 只看一件事：**每个新用户的获取成本**是否低于**他 7 天内带来的广告收入**。低于才加预算，否则先改游戏。

### 其他
- **抖音小游戏**：代码几乎一样，可以作为第二个渠道。
- **公益合作**（小院）：和真实的动物救助机构合作，玩家每送养一只就捐一份真实粮食。必须真的捐，适合做媒体宣传。

## 6. 上线后看哪些数据

| 指标 | 含义 | 参考目标 |
| :--- | :--- | :--- |
| 次日留存 | 第二天还回来玩的比例 | 30% 以上算不错 |
| 人均时长 | 每人每天玩多久 | 越长广告机会越多 |
| 人均激励广告次数 | 每人每天看几次 | 2–4 次比较健康 |
| 广告收入 / 新用户成本 | 能不能放量买量 | 大于 1 才放量 |

`ad-kit` 的 `onEvent` 会报告每次广告的展示、完成、失败，可以接到统计后台。

## 7. 时间表（参考）

| 时间 | 事情 |
| :--- | :--- |
| 第 1 周 | 注册账号、提交备案、申请软著；开始移植云霄突围 |
| 第 2 周 | 真机测试、接广告位、做分享卡片 |
| 第 3–6 周 | 等软著；拍短视频，先在网页版和海外积累反馈 |
| 软著下来后 | 提交审核上线，开通流量主，开始小预算测试 |
