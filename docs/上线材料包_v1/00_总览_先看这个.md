- 泰国包：5 段巴利文 `draft` → `self-checked`（带自查记录）；4 处译文、2 处事实错误、2 处泰文界面用词。
- 泰国佛日：2026 年 50 个佛日改用泰国通行年历（不再是估算）；出雨安居 2026-10-26 改为确切日期；2027 年起仍估算并标注。
- 繁体：佈施→布施、唸佛→念佛、唸經→念經、賬號→帳號，写进转换脚本。
- English：3 处用词。
- 平台：隐私说明改为如实写明 GitHub Pages、Google Fonts 和在线朗读语音；新增“隐私政策与用户协议”页面并从设置页链接；字体不阻塞首屏；离线缓存升到 v5。
- 菩提静院：面板打开时提示条移到顶部，不再挡住按钮。
- 测试：53 项全部通过，新增对年历佛日、自查记录的检查。

## 4. 需要你拍板的三件事

1. **英文品牌名**：推荐“Qifei · Threshold”（中文“启扉”不变）。见 04。
2. **国内版本**：推荐先只做国际版；国内版等律师意见，做的话只做世俗版。见 11。
3. **先找哪位顾问**：推荐先找泰国顾问（泰国包离正式版只差顾问和录音），汉传顾问同时联系。见 07。

## 6. 签完字以后，开发要做的（每项十分钟以内）

- 顾问签字 → `content.js` 的 `reviewStatus` 改 `advisor-approved`，写入 `reviewers`。
- 母语审校签字 → `registry.js` 里语言状态 `draft` → `ok`。
- 泰国顾问签字 → 泰国版本 `preview` → `live`。
- 录音交付 → `pack.js` 的 `VOICES` 填文件、诵读者、授权、校音人，选项 `off` → `ok`。
- 每一步之后运行 `node tools/release-check.mjs`，阻塞项归零即可正式发布。

## 7. 诚实说明

- 本轮的“审校”和“顾问自查”都是 AI 做的。平台的审核等级里，AI 自查最多到 `self-checked`。我没有把任何内容标成 `native-reviewed` 或 `advisor-approved`，因为这两个等级的意思就是“有真人签字”；替人签字会让审核门失去意义。
- 商标检索用的是公开网页和第三方聚合站，没有登录官方数据库。
- 法规部分是产品经理的梳理，不是法律意见。
